Modern web teknolojileri kullanılarak geliştirilmiş, yüksek performanslı ve estetik odaklı kişisel portfolyo web sitesi.

## ✨ Özellikler

- **🌍 Çok Dilli Destek:** Türkçe ve İngilizce dil seçenekleri arasında dinamik geçiş (Context API).
- **🎭 Gelişmiş Animasyonlar:** GSAP ve Framer Motion ile akıcı kullanıcı deneyimi ve mikro-etkileşimler.
- **📱 Duyarlı Tasarım:** Tailwind CSS ile tüm cihazlarla %100 uyumlu (Mobil, Tablet, Masaüstü).
- **🎨 Modern Estetik:** Karanlık ve aydınlık mod uyumlu, minimalist ve profesyonel tasarım dili.
- **🧩 Bileşen Odaklı Yapı:** Next.js App Router ve modüler klasör yapısı ile sürdürülebilir kod tabanı.

## 🛠️ Teknolojiler

- **Framework:** Next.js (App Router)
- **UI Kütüphanesi:** React 19
- **Stil:** Tailwind CSS
- **Animasyon:** GSAP, Framer Motion
- **İkonlar:** Lucide React
- **Dil Desteği:** Custom Language Context

## 📁 Proje Yapısı

```text
├── app/             # Sayfa yönlendirmeleri ve global stiller
├── components/      # Tekrar kullanılabilir UI bileşenleri
│   ├── sections/    # Sayfa bölümleri (Hero, About, Projects vb.)
│   └── ...
├── context/         # Global durum yönetimi (Dil, Tema vb.)
├── public/          # Statik dosyalar (Görseller, Favicon vb.)
└── tailwind.config.ts # Stil konfigürasyonu
```

## 🚀 Kurulum

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları takip edin:

1. **Depoyu klonlayın:**
   ```bash
   git clone https://github.com/aysesudeozden/aysesudeozden.github.io.git
   cd aysesudeozden.github.io
   ```

2. **Bağımlılıkları yükleyin:**
   ```bash
   npm install
   ```

3. **Geliştirme sunucusunu başlatın:**
   ```bash
   npm run dev
   ```

4. Tarayıcınızda `http://localhost:3000` adresine gidin.

## 📦 Dağıtım (Deployment)

Bu proje **GitHub Pages** veya **Vercel** üzerinde kolayca yayınlanabilir. Üretim sürümü oluşturmak için:

```bash
npm run build
```
